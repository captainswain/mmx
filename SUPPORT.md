# Support

mmx is a community project maintained on a best-effort basis.

- **Bug reports and feature requests:** use the GitHub issue templates.
- **Usage questions:** open a discussion or an issue with the `question` label.
- **Security issues:** follow [`SECURITY.md`](SECURITY.md).
- **Contributing:** read [`CONTRIBUTING.md`](CONTRIBUTING.md).

When reporting a geometry problem, include the input model, the command or UI
action, the expected result, and the actual topology counts (faces, boundary
loops, non-manifold edges). A minimal reproducer is worth more than a screenshot.
